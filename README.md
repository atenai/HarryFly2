# HarryFly2

「ハリーフライ2」

（概要・テーマ）
この作品は、デジタルハリウッド大学院の、ゲームラボという授業で開発した作品です。
元々は、HAL時代に開発したハリーフライの続編を開発するというテーマで制作しました。

(開発時期・期間)
デジタルハリウッド大学院2年生時の2021年4月～2021年6月(3ヶ月)

（開発ツール）
・ゲームエンジン：Unity(バージョン2020.3.16f1)
・言語：C#
・開発環境：Visual Studio Code
・3D データ制作：blender・Maya 

（チームメンバー）
開発チーム（計4人）
・プランナー1人（担当）
・プログラマー1人
・デザイナー2人

（ゲームシステム）
制限時間内にUAVでゴールを目指すゲームです。
・燃料を取るとブースト時間が回復します。
・障害物に当たると押し戻されます。
・時間制限が来るとゲームオーバーになります。
・赤い枠に到達したらゲームクリアーになります。

(操作方法)
・AとDキーでUAVを左右移動させることができます。
・WとSキーでUAVを上下移動させることができます。
・スペースキーでUAVを加速させることができます。

(起動方法)
「HarryFly(ビルド)」というフォルダーを開いてください。
その中にある、「New Unity Project.exe」というアプリケーションをダブルクリックしてください。
